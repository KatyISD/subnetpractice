💡 Subnetting Tips
  • Network Address: The first IP in the subnet (all host bits = 0)
  • Broadcast Address: The last IP in the subnet (all host bits = 1)
  • First Available: Network address + 1
  • Last Available: Broadcast address - 1
  • Available Hosts: 2^(host bits) - 2 (excluding network and broadcast)
  • Quick CIDR reference: /24 = 256 IPs, /25 = 128, /26 = 64, /27 = 32, /28 = 16, /29 = 8, /30 = 4
